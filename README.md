# Projeto de Threads em Java

## Autores

Desenvolvido por João Victor Lima Venceslau e Rayssa Silva de Oliveira

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de estudar e aplicar os conceitos de **Threads em Java**, explorando a execução concorrente de tarefas e o funcionamento de múltiplas linhas de execução em uma aplicação.

A proposta é compreender como as threads permitem executar diferentes processos de maneira independente, contribuindo para o desenvolvimento de aplicações mais eficientes.

## Tecnologias utilizadas

- **Java** – Linguagem de programação utilizada no desenvolvimento.
- **Apache NetBeans** – Ambiente de desenvolvimento integrado (IDE).

## Conceitos abordados

- Criação e execução de Threads.
- Programação concorrente.
- Ciclo de vida das Threads.
- Execução simultânea de tarefas.
- Gerenciamento de processos concorrentes.

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Abra o Apache NetBeans.

3. Selecione **File → Open Project**.

4. Localize a pasta do projeto e abra-o.

5. Execute a classe principal do programa.

## Objetivo acadêmico

Projeto acadêmico desenvolvido para praticar e aprofundar os conhecimentos sobre programação concorrente em Java, utilizando Threads e seus principais conceitos.
